# Sessão F0 — Fundação (semanas 1–2)

Cole o texto abaixo como primeira mensagem da sessão no Devin.

---

Você vai iniciar o projeto "Pauta", um app web de geração automática de conteúdo para Instagram.

Antes de começar, leia nesta ordem: `AGENTS.md`, `docs/PRD.md` (principalmente as seções 5, 7 e 8) e `docs/design/README.md`. Siga as decisões de arquitetura do `AGENTS.md` sem alterar: só Vercel + Supabase, sem workers, filas ou Redis.

**Objetivo desta sessão (fase F0):**

1. Scaffold do app: Next.js (App Router) + TypeScript estrito + Tailwind + shadcn/ui + ESLint/Prettier, com pnpm.
2. Supabase: projeto local (`supabase init`), migrations com as 13 entidades da seção 8 do PRD (incluindo `PipelineRun`), pgvector habilitado, RLS por `workspace_id`.
3. Auth com Supabase (Google e e-mail). Ao criar conta, criar um `Workspace` padrão.
4. Layout base com a sidebar e os tokens de `docs/design/README.md` (Fraunces + Manrope), e as rotas vazias: Dashboard, Radar, Estúdio, Calendário, Brand Kit, Configurações.
5. Tela de **Brand Kit** funcional (referência: `docs/design/BrandKit.dc.html`): upload de logos claro/escuro no Storage, paleta, fontes, tom de voz, posts de referência, lista "nunca usar". Salvar em `BrandKit`.
6. Conexão com a Meta: fluxo OAuth para conta profissional do Instagram, guardando o token criptografado (`TOKEN_ENCRYPTION_KEY`) em `SocialAccount`, com `token_expires_at`.
7. Esqueleto das interfaces em `src/lib/providers/`: `SearchProvider`, `LLMProvider`, `MediaProvider`, `ChannelAdapter` (só tipos e uma implementação mock de cada).
8. `vercel.json` já declarando os crons (`/api/cron/publish` a cada minuto, `/api/cron/daily` 1x por dia), com as rotas protegidas por `CRON_SECRET` e retornando 200 sem fazer nada por enquanto.
9. `.env.example` atualizado se precisar de novas variáveis; README com instruções para rodar local.

**Critério de pronto:**

- Deploy de preview na Vercel funcionando.
- Consigo criar conta, preencher e salvar o Brand Kit, e conectar uma conta profissional do Instagram de teste.
- Migrations rodam do zero sem erro; testes passam no CI.
- PR aberto com descrição, como testar e o checklist acima.

**Fora do escopo desta sessão:** pesquisa, geração com IA, render, publicação e cobrança.

Se algo no PRD estiver ambíguo, pergunte antes de decidir. Me avise também quais chaves e contas você precisa que eu crie.
